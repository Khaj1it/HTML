# HTML
проект по СИТ 
 Задание

1. Выбрать тему сайта (НЕ ИНТЕРНЕТ-МАГАЗИН), требования к содержанию:

включает текстовую и графическую информацию;
содержит данные, представляемые в табличном виде, чтобы их можно было использовать для построения диаграмм и графиков, сортировки и фильтрации (не менее 50 строк в таблице).
Важно! ОБЯЗАТЕЛЬНО СОГЛАСОВАТЬ ТЕМУ С ПРЕПОДАВАТЕЛЕМ, подобранные для сайта материалы будут использоваться в других проектах курса. 

2. Разработать структуру сайта (пример example.pdf прикреплен к текущему заданию), требования к структуре:

состоит из не менее 3-страниц:
главная страница;
страница с подробным описанием одного объекта, представленного на первой cтранице;
страница с табличными данными и формами для их обработки. 
главная страница включает (как минимум):
раздел меню;
раздел с рисунками (чтобы потом можно было сделать галерею);
основное содержание (несколько блоков текста с картинками);
Футтер, в котором указать группу и фамилию разработчика (как минимум).
страница с табличными данными включает:
таблицу;
формы для настройки графика, сортировки и фильтров.
3. Создать сайт, требования к реализации:

язык реализации - HTML(без стилей);
НЕ ИСПОЛЬЗОВАТЬ табличный дизайн страниц;
включить следующие элементы html-страницы (как минимум): заголовки, абзацы, списки, раскрывающиеся элементы, гиперссылки, рисунки, таблицы, формы;
форматировать элементы с помощью атрибутов.
4. Выполнить валидацию сайта. Для валидации html-страниц использовать https://validator.w3.org/. После валидации в коде могут остаться только ошибки Use CSS instead.
